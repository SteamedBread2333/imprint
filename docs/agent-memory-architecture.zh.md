## 共享架构一览

```mermaid
flowchart TB
  U[用户] --> A[编码智能体]

  A -->|写代码前| R[联合检索]
  A -->|durable 偏好| W[写入分类 → 记忆库]

  R --> V[(结构化记忆库)]
  R --> S[(文档索引层)]
  W --> V
  V <-->|出处指针| S
```

| 组件 | 职责 |
| --- | --- |
| **结构化记忆库** | 短条目、依据、置信度、标签、条目关系、出处指针 |
| **文档索引层** | Markdown 分块、全文检索、文档内条目引用 |
| **联合检索** | 读时合并两库，Top-N + 摘要片段（Token 专题） |
| **写入分类** | 新增 / 强化 / 替换 / 忽略 / 删除（防幻觉专题） |
